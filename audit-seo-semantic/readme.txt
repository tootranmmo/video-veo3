Comprehensive SEO audit tool with Technical Audit, Backlink Audit, and Content Audit features.

== Description ==

Audit SEO Semantic is a powerful WordPress plugin that helps you optimize your website for search engines. It provides three main audit features:

**Technical Audit**
* Analyze meta tags (title, description)
* Check heading structure (H1-H6)
* Validate URL structure
* Check image optimization
* SSL/HTTPS status
* Structured data validation
* Robots meta analysis

**Backlink Audit**
* Manage backlink database
* Track DoFollow/NoFollow links
* Monitor domain authority
* Analyze spam scores
* Track anchor text distribution
* Identify toxic links
* View backlink statistics

**Content Audit**
* Analyze content length
* Calculate readability score
* Check keyword density
* Optimize focus keywords
* Validate paragraph structure
* Analyze internal/external links
* Get LSI keyword suggestions

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/audit-seo-semantic` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Use the SEO Audit menu to configure and use the plugin

== Frequently Asked Questions ==

= How do I run a technical audit? =

Go to SEO Audit > Technical Audit, select a post or page, and click "Run Technical Audit". The plugin will analyze your content and provide a score with recommendations.

= Can I export audit results? =

This feature is planned for a future release. Currently, you can view and analyze results in the WordPress admin.

= How is the SEO score calculated? =

The plugin uses a point-based system analyzing various SEO factors. Each factor has a weight, and the total score is calculated as a percentage.

= Does this plugin work with page builders? =

Yes, the plugin works with any WordPress content, including content created with page builders.
